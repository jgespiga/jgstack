# Redesign From First Principles

**When:** integrating a new requirement into an existing design.

Don't bolt it on. Redesign as if the requirement had been a foundational assumption from the start.

- Read all affected files and understand the current design.
- Ask: "if we wrote this from scratch with this requirement, what would we build?"
- Propagate the change through every reference: types, docs, examples, rationale.
- Think through the whole redesign, then deliver it incrementally.

This questions the design, not a fact it assumes (for that, see `attack-the-premise.md`).
